# Math AI Final Project - Variational Autoencoder (VAE)

## 📌 Overview
This project explores the mathematical framework, optimization metrics, and implementation of Variational Autoencoders (VAEs). It contains pipelines for extracting structured text from mathematical physics PDFs and a generative workflow to approximate complex data distributions.

---

## 📁 Project Structure
The repository has been restructured into a modular format following standard engineering practices:

```text
Math-AI-Final-Project/
├── data/          # Raw datasets used for training (e.g., veri.csv)
├── src/           # Core Python source scripts (extraction & presentation generation)
├── notebooks/     # Interactive Jupyter Notebook experiments and model training
├── reports/       # Academic PDFs, extracted text segments, and visual results
└── presentation/  # Exported presentation materials and speaker notes
