        <!-- Slide 3: Theory - ELBO -->
        <div class="slide">
            <h2>Teorik Çerçeve: ELBO</h2>
            
            <p>Amaç, gözlemlenebilir veri <strong>x</strong> için log-olabilirliği maksimize etmek:</p>
            
            <div class="formula">
                log p(x) ≥ 𝔼<sub>q(z|x)</sub>[log p(x|z)] − D<sub>KL</sub>(q(z|x) ∥ p(z))
            </div>
            
            <div class="two-column">
                <div class="column">
                    <h3>📐 Jensen Eşitsizliği</h3>
                    <p>ELBO, Jensen eşitsizliği kullanılarak türetilir. KL ≥ 0 olduğu için, ELBO her zaman log p(x)'in altında kalır.</p>
                </div>
                <div class="column">
                    <h3>🎲 Terimler</h3>
                    <ul>
                        <li><strong>Reconstruction:</strong> Veri yeniden oluşturma</li>
                        <li><strong>KL Divergence:</strong> Latent dağılım düzenlileştirme</li>
                    </ul>
                </div>
            </div>
            <div class="slide-number">3 / 12</div>
        </div>

        <!-- Slide 4: Reparameterization -->
        <div class="slide">
            <h2>Reparameterization Trick</h2>
            
            <p>Stokastik örneklemeyi <strong>türevlenebilir</strong> hale getirmek için:</p>
            
            <div class="formula">
                z = μ + σ ⊙ ε, &nbsp;&nbsp;&nbsp; ε ~ 𝒩(0, I)
            </div>
            
            <div class="highlight-box">
                <h3>💡 Neden Önemli?</h3>
                <p>Rastgelelik (ε) ağ parametrelerinden ayrılır. Böylece gradyanlar doğrudan μ ve σ üzerinden akabilir ve backpropagation mümkün olur.</p>
            </div>
            
            <div class="code-block">
                <pre><span class="keyword">def</span> <span class="function">reparameterize</span>(self, mu, logvar):
    <span class="comment"># z = μ + σ ⊙ ε,  where ε ~ N(0, I)</span>
    std = torch.<span class="function">exp</span>(<span class="number">0.5</span> * logvar)
    eps = torch.<span class="function">randn_like</span>(std)
    z = mu + eps * std
    <span class="keyword">return</span> z</pre>
            </div>
            <div class="slide-number">4 / 12</div>
        </div>

        <!-- Slide 5: Architecture -->
        <div class="slide">
            <h2>VAE Mimarisi</h2>
            
            <div class="architecture">
                <div class="arch-box encoder">
                    <h4>Encoder</h4>
                    <p>784 → 400 → 2</p>
                    <p style="color: #e94560;">q(z|x)</p>
                </div>
                <span class="arrow">→</span>
                <div class="arch-box latent">
                    <h4>Latent Space</h4>
                    <p>μ, log σ²</p>
                    <p style="color: #f39c12;">2-dim</p>
                </div>
                <span class="arrow">→</span>
                <div class="arch-box decoder">
                    <h4>Decoder</h4>
                    <p>2 → 400 → 784</p>
                    <p style="color: #2ecc71;">p(x|z)</p>
                </div>
            </div>
            
            <div class="code-block">
                <pre><span class="keyword">class</span> <span class="function">VAE</span>(nn.Module):
    <span class="keyword">def</span> <span class="function">__init__</span>(self, latent_dim=<span class="number">2</span>):
        <span class="comment"># Encoder: x → (μ, log σ²)</span>
        self.encoder = nn.Sequential(nn.Linear(<span class="number">784</span>, <span class="number">400</span>), nn.ReLU())
        self.fc_mu = nn.Linear(<span class="number">400</span>, latent_dim)
        self.fc_logvar = nn.Linear(<span class="number">400</span>, latent_dim)
        <span class="comment"># Decoder: z → x</span>
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, <span class="number">400</span>), nn.ReLU(),
            nn.Linear(<span class="number">400</span>, <span class="number">784</span>), nn.Sigmoid()
        )</pre>
            </div>
            <div class="slide-number">5 / 12</div>
        </div>

        <!-- Slide 6: Loss Function -->
        <div class="slide">
            <h2>Kayıp Fonksiyonu</h2>
            
            <div class="formula">
                ℒ = BCE(x, x̂) + D<sub>KL</sub>(q(z|x) ∥ 𝒩(0, I))
            </div>
            
            <div class="two-column">
                <div class="column">
                    <h3>🔴 Reconstruction (BCE)</h3>
                    <p>Piksel bazlı Binary Cross-Entropy: Görüntünün ne kadar iyi yeniden oluşturulduğunu ölçer.</p>
                </div>
                <div class="column">
                    <h3>🟢 KL Divergence</h3>
                    <p>Latent dağılımın Gaussian prior'dan sapmasını ölçer. Kapalı form çözümü vardır.</p>
                </div>
            </div>
            
            <div class="code-block">
                <pre><span class="keyword">def</span> <span class="function">vae_loss</span>(recon_x, x, mu, logvar):
    <span class="comment"># Reconstruction Loss</span>
    recon = F.<span class="function">binary_cross_entropy</span>(recon_x, x, reduction=<span class="string">'sum'</span>)
    <span class="comment"># KL Divergence (closed form for Gaussian)</span>
    kl = <span class="number">-0.5</span> * torch.<span class="function">sum</span>(<span class="number">1</span> + logvar - mu.<span class="function">pow</span>(<span class="number">2</span>) - logvar.<span class="function">exp</span>())
    <span class="keyword">return</span> recon + kl</pre>
            </div>

        function moveSlide(direction) {
            currentSlide += direction;
            
            // Loop boundaries (optional: you can stop at ends instead)
            if (currentSlide < 0) currentSlide = 0;
            if (currentSlide >= totalSlides) currentSlide = totalSlides - 1;
            
            updateSlidePosition();
        }

        function updateSlidePosition() {
            // Move the wrapper by negative percentage of current slide
            wrapper.style.transform = `translateX(-${currentSlide * 100}vw)`;
            updateProgress();
        }

        function updateProgress() {
            const percentage = ((currentSlide + 1) / totalSlides) * 100;
            progressBar.style.width = `${percentage}%`;
        }

        // Keyboard navigation
        document.addEventListener('keydown', (e) => {
            if (e.key === 'ArrowRight' || e.key === ' ') {
                moveSlide(1);
            } else if (e.key === 'ArrowLeft') {
                moveSlide(-1);
            }
        });

        // Touch swipe support for mobile
        let touchStartX = 0;
        let touchEndX = 0;

        document.addEventListener('touchstart', (e) => {
            touchStartX = e.changedTouches[0].screenX;
        });

        document.addEventListener('touchend', (e) => {
            touchEndX = e.changedTouches[0].screenX;
            handleSwipe();
        });

        function handleSwipe() {
            if (touchEndX < touchStartX - 50) moveSlide(1); // Swipe Left -> Next
            if (touchEndX > touchStartX + 50) moveSlide(-1); // Swipe Right -> Prev
        }
    </script>
